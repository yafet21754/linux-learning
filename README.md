# Kinetic — adaptive workout dashboard

A polished, responsive workout experience built with plain HTML, CSS, and JavaScript. Kinetic includes a live workout timer, exercise progression, quick activity logging, an interactive weekly chart, goal controls, and an AI coach interface.

## Run locally

```bash
npm start
```

Then open <http://localhost:4173>.

The server listens on `0.0.0.0`, so hosted workspaces can expose port `4173`
through their **Ports** or **Preview** panel. If you are using a remote workspace,
open the forwarded/public URL shown for port `4173` instead of typing localhost
on your own computer.
